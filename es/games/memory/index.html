🃏 Memoria

Voltea dos cartas a la vez: si coinciden, se quedan abiertas. ¡Encuentra las 8 parejas en el menor número de movimientos!

Movimientos0
Parejas0 / 8
Tiempo (s)0

🎯 Cómo jugar

  • Toca una carta para voltearla; solo dos pueden estar abiertas a la vez.
  • Si los dibujos coinciden, la pareja queda descubierta.
  • Si no, se voltean de nuevo. ¡Recuerda dónde estaban!
  • Encuentra las 8 parejas para ganar; menos movimientos, mejor puntuación.

💡 Consejos

  • Voltea en orden y numera mentalmente las posiciones.
  • Al ver un dibujo nuevo, recuerda si ya apareció.
  • Descarta las parejas logradas para reducir lo que memorizas.
